# BALL46 Android

Android WebView shell for BALL46.

- Package: `com.ball46.app`
- Version: `1.0.0-beta1`
- Website: `https://ball46.com/`
- Internal links: BALL46 domain and subdomains stay inside the app
- External links: open in the device browser
- Live football data stays on the existing BALL46 web platform; no duplicated live-data engine is embedded in the APK
