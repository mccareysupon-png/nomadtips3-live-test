การวัดการเข้าชมแบบยินยอมของ BALL46

ข้อมูลสำหรับส่วน Online browsers, Unique browsers และ Sessions ใน BALL46 VISITOR MONITOR เจ้าของระบบคือ BALL46 Team ติดต่อ jay@ball46.com

  • ระบบนี้เริ่มส่งข้อมูลหลังคุณเลือก “ยินยอม” เท่านั้น การปฏิเสธไม่มีผลต่อการใช้เว็บไซต์ ไม่มีการใช้เพื่อโฆษณาหรือติดตามข้ามเว็บไซต์
  • วัดเฉพาะหน้าสาธารณะของ ball46.com และ www.ball46.com ไม่เก็บหน้าสมาชิก หน้าเข้าสู่ระบบ หรือชำระเงิน
  • ใช้รหัสสุ่มของเบราว์เซอร์ (หมดอายุใน 30 วัน) และรหัส Session ที่เปลี่ยนเมื่อไม่มีกิจกรรมเป็นเวลา 30 นาที เก็บใน LocalStorage ของแต่ละ host ไม่มีการตรวจลายนิ้วมืออุปกรณ์
  • ส่งเฉพาะรหัสสุ่ม หน้าเว็บสาธารณะที่อยู่ในรายการอนุญาต และความยินยอม ไม่ส่ง query string, fragment, referrer, ข้อความที่พิมพ์ หรือการกดปุ่ม การตรวจการเลื่อน/กดปุ่มในเบราว์เซอร์ใช้เพื่อหยุด Session ที่ไม่ได้ใช้งานเท่านั้นและไม่มีการส่งรายละเอียดออกไป
  • เซิร์ฟเวอร์เพิ่มเวลารับข้อมูล ประเทศระดับประเทศ และประเภทอุปกรณ์ Mobile/Desktop บน Cloudflare ของ BALL46 รหัสสุ่มถูกแฮชก่อนเก็บใน KV แยกของ VISITOR MONITOR ข้อมูลนี้ลบอัตโนมัติภายใน 26 ชั่วโมงหลังข้อมูลล่าสุดของแต่ละรหัส
  • ส่วนนี้ไม่เก็บ IP จริงหรือ IP ที่ปิดบางส่วนลงฐานข้อมูล แอปไม่เขียนข้อมูลผู้ชมลง log อย่างไรก็ตาม Cloudflare ต้องประมวลผล IP และข้อมูลเครือข่ายเพื่อให้บริการและป้องกันการใช้งานผิดปกติ
  • ส่ง heartbeat ประมาณทุก 45 วินาทีเฉพาะหน้าที่มองเห็นและมีกิจกรรมภายใน 30 นาที “ออนไลน์” หมายถึงเบราว์เซอร์ที่ยินยอมและมี heartbeat ภายใน 2 นาที ไม่ยืนยันว่ามีบุคคลกำลังมองหน้าจอ ข้อมูล KV อาจล่าช้า 60 วินาทีขึ้นไป
  • นับเบราว์เซอร์ไม่ซ้ำ ไม่ใช่บุคคลจริง การเปลี่ยนเบราว์เซอร์ อุปกรณ์ host หรือลบ LocalStorage อาจถูกนับเป็นรหัสใหม่ Sessions คือรหัส Session ที่มีกิจกรรมใน 24 ชั่วโมงล่าสุด ไม่มีการสร้างข้อมูลย้อนหลัง
  • เปลี่ยนใจได้จากปุ่ม “ความเป็นส่วนตัว” บนเว็บไซต์ เมื่อถอนจะหยุดส่ง heartbeat ลบรหัสในเบราว์เซอร์ และส่งคำขอลบข้อมูลของรหัสนั้นไปเซิร์ฟเวอร์ การลบจาก KV อาจมีความล่าช้า หากคำขอลบไปไม่ถึง ข้อมูลเซิร์ฟเวอร์จะหมดอายุภายใน 26 ชั่วโมง ตัวเลือกปฏิเสธคงอยู่ในเบราว์เซอร์เพื่อไม่ถามซ้ำ
  • เคารพสัญญาณ Do Not Track (DNT) และ Global Privacy Control (GPC) ปิดการเก็บข้อมูลเมื่อเบราว์เซอร์ส่งสัญญาณดังกล่าว
  • รายงานและตัวเลขการเข้าชมเข้าถึงได้เฉพาะเจ้าของผ่าน Cloudflare Access ตัว Collector สาธารณะรับข้อมูลได้แต่ไม่มี API อ่านรายงาน IP ที่แสดงใน Dashboard มาจาก Request Logs เดิมของ Cloudflare เป็นคนละแหล่งกับระบบนี้และไม่เชื่อมรหัสเบราว์เซอร์เข้ากับ IP

ใช้ Cloudflare เป็นผู้ให้บริการประมวลผลโครงสร้างพื้นฐาน การจัดเก็บและประมวลผลอาจเกิดบนเครือข่ายทั่วโลกตาม นโยบาย Cloudflare สามารถติดต่อ BALL46 Team เพื่อสอบถามสิทธิและการจัดการข้อมูล
