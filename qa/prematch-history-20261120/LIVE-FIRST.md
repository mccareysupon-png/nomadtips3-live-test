# Live First isolate runtime
Default history OFF stored independently, tested on real Cloudflare Durable Object using the exact active HUB speed policy and mock responses only. The isolated worker has no provider key, no cron, no production service binding. The test-only mode uses an explicit ISOLATED_SHADOW_ONLY marker, not evidence of whole-account coordination. The 1/minute pacing and existing 20+ live reserve are preserved. Existing priority traffic is unaffected by the history switch. Actual provider 429 would trigger shared cooldown; this simulated 429 is not a production 429. Existing in-flight requests cannot be undone by switching off. Production migrations, all caller disposition and full 10-match import are still gated; no real history activation in this release.
