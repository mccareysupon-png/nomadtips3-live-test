# คู่มือมอนิเตอร์ BALL46 3.43 (ภาษาไทย)

สถานะ: ฉบับเตรียมใช้งานในสาขาทดสอบเท่านั้น ไม่แก้ Production และไม่เปิดตัวตรวจซ้ำ

## ระบบตรวจเดิม
- Workflow: `.github/workflows/ball46-343-health-monitor.yml`
- Script: `operations/ball46-343-monitor/monitor.mjs`
- รอบตรวจ: นาทีที่ 07 และ 37 ของทุกชั่วโมง (UTC)
- รายงาน: `reports/ball46-343-observation.json` และ `reports/ball46-343-summary.md` (GitHub Actions artifact)

## คำแปลสถานะ
- PASS: ผ่านการตรวจในรอบนี้
- WARNING: พบความผิดปกติ ต้องตรวจสอบก่อนแก้
- CRITICAL: บริการหลักตอบสนองผิดปกติ ต้องตรวจทันที
- UNKNOWN: ข้อมูลไม่เพียงพอ ห้ามสรุปว่าปลอดภัย
- PASS_WITH_GAPS: ไม่พบข้อผิดพลาดที่ตรวจวัดได้ แต่ยังมีจุดที่ตรวจไม่ถึง

## รายการเฝ้าระวัง
1. เว็บหลักและเว็บสมาชิก: HTTP, เวลาตอบสนอง, แคช
2. HUB และ Engine 3.43: สุขภาพและรอบดึงข้อมูล
3. Shadow 3.41: ตรวจว่ามี alarm หรือการเรียก provider หลงเหลือหรือไม่
4. Cloudflare Workers: จำนวนการเรียกและข้อผิดพลาดในช่วง 20 นาที
5. Deployment และ Cron: ตรวจ metadata โดยไม่สั่งเปลี่ยน

## ข้อจำกัดสำคัญ
- จำนวน Worker errors **ไม่ใช่** จำนวน HTTP 429 จาก 5DollarFootballAPI
- ยังไม่มีข้อมูล X-RateLimit-Remaining, Retry-After และ HTTP 429 ต่อคำขอจริง
- การไม่มี alarm ในช่วงตรวจ **ไม่ยืนยัน** ว่า Worker ถูกปิดถาวร
- ยังไม่ได้ยืนยันรายชื่อ Worker ทั้งบัญชี Cloudflare หรือทุก route/cron

## เงื่อนไขก่อนปิด Worker เก่า
ต้องยืนยันพร้อมกันว่า (1) ไม่ใช่ Worker ที่ระบบใช้งานจริง (2) ไม่มี route/service binding หรือ Cron ที่จำเป็น (3) มีหลักฐานการยิง API ซ้ำ (4) มีแผนย้อนกลับและได้รับอนุมัติจากเจ้าของ

**ห้ามปิด ลบ หรือ Deploy โดยอาศัยรายงานนี้เพียงอย่างเดียว**
