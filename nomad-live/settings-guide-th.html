สูตรจำง่าย: Side กับ Allowed Lines เป็นคนละหน้าที่

Detection Side ตอบว่า “ตรวจฝั่งไหน” ส่วน Allowed Lines ตอบว่า “ยอมรับ AH line แบบไหน”

ANY VALID AH LINE + HOME = HOME
ANY VALID AH LINE + AWAY = AWAY
ANY VALID AH LINE + BOTH = BOTH

SELECTED SIDE LINES + HOME = HOME
SELECTED SIDE LINES + AWAY = AWAY
SELECTED SIDE LINES + BOTH = BOTH
ความหมาย: Allowed Lines ไม่ได้เปลี่ยนคำตอบว่าเป็น HOME / AWAY / BOTH แต่มีผลต่อการกรอง AH line ที่ candidate ฝั่งนั้นต้องผ่าน
ถ้าต้องการกรอบ 0 → +5:
SELECTED SIDE LINES (0 → +5) + HOME = HOME เฉพาะ 0 → +5
SELECTED SIDE LINES (0 → +5) + AWAY = AWAY เฉพาะ 0 → +5
SELECTED SIDE LINES (0 → +5) + BOTH = BOTH เฉพาะ 0 → +5
ANY = ไม่ใช้ Selected Side Lines: ต่อให้มีรายการ 0, +0.25, +0.50 ฯลฯ ถูกเลือกค้างอยู่ในช่อง Selected Side Lines ระบบจะไม่ใช้รายการนั้นกรอง จนกว่าจะเปลี่ยน Allowed Lines เป็น SELECTED SIDE LINES

ENGINE TRUTH

Active Settings

ค่าที่แสดงใน Active Settings คือค่าที่ engine ใช้งานจริง ค่าที่แก้ในฟอร์มแต่ยังไม่ได้ Save ยังไม่มีผล

Active Version / Last Updated / Applies From Cycle

ใช้ตรวจว่า Settings เวอร์ชันใด Active และเริ่มมีผลตั้งแต่ cycle ใด SIGNAL ที่ถูก lock แล้วจะเก็บ config snapshot ของตัวเอง ไม่ถูกเปลี่ยนย้อนหลังเมื่อแก้ Settings ภายหลัง

A · DETECTION WINDOW

Time and score gate

ด่านเวลาและสกอร์ใช้กติกาเดียวกันไม่ว่าจะเลือก HOME, AWAY หรือ BOTH

Minute From / Minute To

กำหนดช่วงนาทีที่อนุญาตให้หา SIGNAL เช่น 35–88 หมายถึงก่อนนาที 35 และหลังนาที 88 ไม่ผ่านด่านเวลา

Rolling Window Minutes

กำหนดขนาดหน้าต่างล่าสุดที่ใช้วัดแรงกดดันและเปรียบเทียบกับหน้าต่างก่อนหน้า เช่น 5 นาที = ช่วงล่าสุด 5 นาทีเทียบกับ 5 นาทีก่อนหน้า

Score Difference Filter / Max Score Difference

เมื่อ Filter = OFF ค่า Max Score Difference ไม่ใช้ตัด เมื่อ ON จึงใช้ผลต่างประตูสูงสุดตามค่าที่ตั้ง

B · SIDE EVIDENCE

Pressure, trend and events

คำว่า Selected Side หมายถึง candidate ที่กำลังถูกตรวจในรอบนั้น HOME ใช้สถิติ HOME, AWAY ใช้สถิติ AWAY, BOTH สร้างสอง candidate แล้วตรวจแยกกัน

Attack Weight / Dangerous Attack Weight

ใช้คำนวณแรงกดดันของ candidate จาก Attack และ Dangerous Attack ตามน้ำหนักที่ตั้งไว้

Selected Side Pressure Share %

candidate ต้องมี Pressure Share ถึงขั้นต่ำที่ตั้ง เช่น ≥60% หมายถึงฝั่งที่กำลังตรวจต้องครอง pressure อย่างน้อย 60%

Trend Conditions Required

จำนวนเงื่อนไข trend ที่ต้องผ่านจาก 3 ข้อ: Side Pressure Trend, Side Pressure Share และ Match Tempo Trend

Event Gate / SOT / Shot Off / Corner / Evidence

ตรวจ event ใหม่ของ Selected Side ตามค่าที่เปิดและขั้นต่ำที่ตั้ง ANY = อย่างน้อยหนึ่ง event ที่เปิดผ่าน, ALL = ทุก event ที่เปิดต้องผ่าน

C · ASIAN HANDICAP

Live market and price gate

ส่วนนี้เป็นจุดสำคัญที่สุดในการกำหนดฝั่งและกรอบราคา

MarketFull Match Live AH
Detection SideHOME / AWAY / BOTH
Allowed LinesANY / SELECTED

1. Detection Side

HOMEตรวจ HOME stats + HOME AH + HOME odds
AWAYตรวจ AWAY stats + AWAY AH + AWAY odds
BOTHตรวจ HOME และ AWAY แยก candidate ด้วยกติกาชุดเดียวกัน

2. Allowed Lines = ANY valid AH line

รับ AH line ทุกค่าที่ระบบถือว่า valid โดย ไม่ใช้ Selected Side Lines เป็นตัวกรอง

ANY + BOTH = ตรวจทั้ง HOME และ AWAY ทุก valid AH line หากผ่านเงื่อนไขอื่น

3. Allowed Lines = Selected side lines

รับเฉพาะ AH line ที่เลือกไว้ในช่อง Selected Side Lines และเทียบจากมุมของ candidate ฝั่งนั้น

ถ้าเลือก 0 → +5 และ Detection Side = BOTH → HOME candidate ต้องมี HOME AH อยู่ใน 0 → +5 และ AWAY candidate ต้องมี AWAY AH อยู่ใน 0 → +5

4. Selected Side Lines

+5 ถึง -5 · ทีละ 0.25

ช่องนี้มีผลเฉพาะเมื่อ Allowed Lines = Selected side lines เท่านั้น เลือกหลายค่าได้ด้วย Ctrl/Cmd หรือ Shift

ตัวอย่าง: ตลาด HOME -0.25 / AWAY +0.25 และตั้งกรอบ 0 → +5 → HOME -0.25 ไม่อยู่ในกรอบ แต่ AWAY +0.25 อยู่ในกรอบ

5. Minimum Odds / Maximum Odds

ตรวจค่าน้ำของ candidate ฝั่งเดียวกับที่กำลังพิจารณา HOME ตรวจ HOME odds, AWAY ตรวจ AWAY odds, BOTH ตรวจแยกสองฝั่ง

6. Maximum Price Age

จำกัดอายุ quote ราคาสูงสุด หากเก่ากว่าค่าที่ตั้งจะถือว่า stale และไม่ใช้สร้าง SIGNAL

7. One Signal Per Match

ON = คู่หนึ่ง lock ได้หนึ่ง SIGNAL เมื่อ BOTH ประเมินสองฝั่ง ระบบเลือก candidate ที่ผ่านตาม logic แล้ว lock เพียงรายการเดียว

กฎที่ต้องจำ: BOTH ไม่ได้กลับกรอบ Selected Side Lines จากบวกเป็นลบให้ AWAY ถ้าตั้ง 0 → +5 ทั้ง HOME และ AWAY ต้องผ่าน 0 → +5 จากมุมของฝั่งตัวเอง
