ENGINE TRUTH

Active Settings

ส่วนนี้บอกค่าที่ engine กำลังใช้งานจริง ไม่ใช่ค่าที่เพิ่งเลือกในฟอร์มแต่ยังไม่ได้ Save

Active Version

หมายเลขเวอร์ชันของชุด Settings ที่ Active อยู่ เมื่อบันทึกค่าใหม่ระบบจะสร้างเวอร์ชันใหม่ และ SIGNAL ใหม่จะเก็บ snapshot ของเวอร์ชันที่ใช้ไว้ด้วย

Last Updated

เวลาที่ Settings เวอร์ชัน Active ถูกบันทึก ใช้ตรวจว่าเครื่องกำลังทำงานด้วยค่าชุดใด

Applies From Cycle

รอบ engine ที่เวอร์ชันนั้นเริ่มมีผล การ Save จะไม่เปลี่ยนกติกากลาง cycle แต่จะเริ่มใช้ตั้งแต่ cycle ถัดไป

หลักสำคัญ: ประวัติ SIGNAL เดิมไม่ถูกเขียนใหม่เมื่อเปลี่ยน Settings ภายหลัง และค่าเก่าที่สร้างก่อนระบบ Side-Aware จะตีความเป็น HOME เพื่อรักษาประวัติเดิม

A · DETECTION WINDOW

Time and score gate

ด่านแรกใช้เหมือนกันทุก Side ไม่ว่าเลือก HOME, AWAY หรือ BOTH

1. Minute From

Default 550–120 นาที

นาทีแรกที่อนุญาตให้เกมผ่านด่านเวลา ก่อนถึงค่านี้ engine ยังเก็บข้อมูลเพื่อสร้าง rolling window ได้ แต่ยังไม่ผ่าน Minute gate

ลดค่าเริ่มพิจารณาเร็วขึ้น
เพิ่มค่ารอเกมพัฒนามากขึ้น
ตัวอย่าง55 → นาที 54 ไม่ผ่าน, นาที 55 เริ่มผ่านได้

2. Minute To

Default 880–120 นาที

นาทีสุดท้ายที่อนุญาตให้หา SIGNAL ค่า Minute From ต้องไม่มากกว่า Minute To

ลดค่าตัดเกมช่วงท้ายเร็วขึ้น
เพิ่มค่าเปิดช่วงท้ายมากขึ้น
ตัวอย่าง88 → นาที 88 ยังผ่านได้ แต่นาที 89 ไม่ผ่าน

3. Rolling Window Minutes

Default 51–15 นาที

กำหนดขนาดหน้าต่างล่าสุดที่ใช้วัดแรงกดดัน แล้วเทียบกับหน้าต่างก่อนหน้าที่มีขนาดเท่ากัน

Window 5 นาที: ช่วง 65–70 เทียบกับ 60–65

สั้นลงตอบสนองไว แต่แกว่งง่าย
ยาวขึ้นนิ่งขึ้น แต่ตอบสนองช้าลง
Sideคำนวณทั้ง HOME/AWAY จากข้อมูลเดียวกัน

4. Score Difference Filter

Default OFF

เปิดหรือปิดเงื่อนไขผลต่างประตู ถ้า OFF ค่า Max Score Difference จะไม่ใช้เป็นตัวตัด

5. Max Score Difference

Default 10–20 ลูก

ผลต่างประตูสูงสุดที่ยอมรับเมื่อ Score Difference Filter = ON ระบบใช้ค่าสัมบูรณ์ จึงไม่สนว่าทีมใดนำ

ตัวอย่าง: ตั้ง 1 → 1-0, 0-1, 2-1 ผ่าน; 2-0 และ 0-2 ไม่ผ่าน

B · SIDE EVIDENCE

Pressure, hunger and new events

คำว่า “Selected Side” หมายถึงฝั่งที่กำลังถูกประเมินในขณะนั้น HOME ใช้ HOME, AWAY ใช้ AWAY และ BOTH จะประเมินสองฝั่งแยกกันด้วยค่าชุดเดียวกัน

1. Attack Weight

Default 10–10

น้ำหนักของ Attack delta ในสูตร pressure ของฝั่งที่กำลังตรวจ

Side Pressure = Attack Delta × Attack Weight + Dangerous Attack Delta × Dangerous Attack Weight

เพิ่มให้ Attack ธรรมดามีอิทธิพลมากขึ้น
ลดลดอิทธิพล Attack
ข้อกำหนดAttack Weight และ Dangerous Attack Weight ห้ามเป็น 0 พร้อมกัน

2. Dangerous Attack Weight

Default 20–10

น้ำหนักของ Dangerous Attack delta ค่าเริ่มต้นสูงกว่า Attack เพื่อให้การบุกอันตรายมีน้ำหนักมากกว่า

3. Selected Side Pressure Share %

Default 54%0–100%

สัดส่วน pressure ของฝั่งที่ตรวจเทียบกับ pressure รวมของทั้งสองทีม

Side Share = Side Pressure ÷ (HOME Pressure + AWAY Pressure) × 100

HOME mode ใช้ HOME share · AWAY mode ใช้ AWAY share · BOTH คำนวณสองค่าคนละ candidate

4. Trend Conditions Required

Default 2 / 3

จำนวนเงื่อนไข trend ที่ต้องผ่านจาก 3 ข้อ: Side Pressure Trend, Side Pressure Share และ Match Tempo Trend

1 / 3กว้างที่สุด
2 / 3สมดุลค่าเริ่มต้น
3 / 3เข้มที่สุด

5. New Selected Side Event Gate

Default ON

ถ้า ON ฝั่งที่กำลังตรวจต้องมี event ใหม่ตาม Evidence ที่เปิดไว้ใน rolling window ล่าสุด ถ้า OFF ระบบข้ามด่าน event แต่ยังเก็บค่าตัวเลือก SOT / Shot Off / Corner ไว้

6. SOT enabled / SOT Delta Minimum

Default ON / +1

ตรวจ Shot On Target ใหม่ของ Selected Side ภายใน rolling window ล่าสุด ค่า Minimum คือจำนวนเพิ่มขั้นต่ำที่ถือว่าผ่าน

AWAY mode + SOT Minimum 1 → ต้องมี SOT ฝั่ง AWAY เพิ่มอย่างน้อย 1 ในหน้าต่างล่าสุด

7. Shot Off enabled / Shot Off Delta Minimum

Default ON / +1

หลักเดียวกับ SOT แต่ตรวจ Shot Off Target ของ Selected Side

8. Corner enabled / Corner Delta Minimum

Default ON / +1

ตรวจ Corner ใหม่ของ Selected Side ใน rolling window ล่าสุด

9. Evidence Required

Default ANY

ANY = event ที่เปิดใช้งานอย่างน้อยหนึ่งชนิดผ่านขั้นต่ำก็พอ · ALL = event ที่เปิดใช้งานทุกชนิดต้องผ่านขั้นต่ำทั้งหมด

เปิด SOT, Shot Off, Corner ทั้ง 3 และใช้ ANY → SOT +1 อย่างเดียวก็ผ่าน Event Gate ได้; ใช้ ALL → ทั้งสามต้องผ่าน

C · ASIAN HANDICAP

Live market and price gate

ตลาดยังเป็น Full Match Live Asian Handicap เหมือนเดิม กติกา line, odds และ freshness ไม่เปลี่ยน เพียงนำไปตรวจกับฝั่งที่กำลังประเมิน

MarketFull Match Live AH
Detection SideHOME / AWAY / BOTH
Bookmaker labelตามหน้าตั้งค่า

1. Market

Fixed

ใช้ Full Match Live Asian Handicap เท่านั้น ไม่สลับไป 1X2, Goals, Corners หรือราคาก่อนแข่งเมื่อ live AH ไม่มีข้อมูล

2. Detection Side

Default HOME

ตัวเลือกหลักสำหรับกำหนดว่ากติกาทั้งชุดจะตรวจฝั่งใด

HOMEใช้ HOME pressure / events / AH line / HOME odds และ lock selection = HOME
AWAYใช้ AWAY pressure / events / AWAY AH line / AWAY odds และ lock selection = AWAY
BOTHสร้าง candidate HOME และ AWAY แยกกัน แล้วใช้กติกาเดิมตรวจทั้งคู่
BOTH ไม่ได้ผสมสถิติสองทีมเข้าด้วยกัน: HOME candidate และ AWAY candidate ถูกประเมินแยกจากกัน ถ้ามีฝั่งเดียวผ่านก็ใช้ฝั่งนั้น ถ้าทั้งสองฝั่งผ่าน ระบบเปรียบเทียบคุณภาพ candidate ตามสถานะ, จำนวน trend ที่ผ่าน, pressure share, ความสดของราคา และ odds; ถ้าเท่ากันทุกอย่างจึงใช้ HOME เป็นตัวตัดเสมอ

3. Bookmaker

Read only

เป็นข้อความอ้างอิงในหน้าตั้งค่า การตัดสิน SIGNAL จริงยังผ่าน price-source validation ของ engine ตามโครงสร้างระบบ 3.41

4. Allowed Lines

Default ANY

ANY valid AH line ยอมรับ line ที่ถูกต้องทุกค่าในขอบเขตระบบ · Selected side lines ใช้เฉพาะ line ที่เลือกด้านล่าง

สำคัญสำหรับ AWAY: ค่าที่ตรวจคือ handicap จากมุมของฝั่งที่เลือก ไม่ใช่ canonical HOME line เสมอ

5. Selected Side Lines

หน้า UI: +5 ถึง -5 ทีละ 0.25

ใช้เมื่อ Allowed Lines = Selected เท่านั้น เลือกหลายค่าได้ด้วย Ctrl/Cmd หรือ Shift

ตัวอย่างการกลับฝั่ง: ตลาด canonical แสดง HOME -0.50 @1.80 / AWAY +0.50 @2.00 → HOME candidate ตรวจ line -0.50; AWAY candidate ตรวจ line +0.50
BOTH + Selected Lines: หากเลือก -0.50 ค่า -0.50 หมายถึง “ฝั่ง candidate ต้องต่อ -0.50” ดังนั้นทั้ง HOME และ AWAY มีสิทธิ์ผ่านได้ หาก handicap จากมุมของฝั่งนั้นเป็น -0.50

6. Minimum Odds

Default 1.501.01–6.00

ราคาต่ำสุดของ Selected Side ที่ยอมรับ HOME mode ตรวจ HOME odds; AWAY mode ตรวจ AWAY odds; BOTH ตรวจ odds ของแต่ละ candidate แยกกัน

Min 1.70: HOME @1.65 ไม่ผ่าน แต่ AWAY @1.92 สามารถผ่านใน AWAY/BOTH ได้ หากเงื่อนไขอื่นของ AWAY ผ่าน

7. Maximum enabled / Maximum Odds

Default OFF1.01–6.00

เมื่อปิด จะไม่มีเพดาน odds ด้านบน เมื่อเปิด ราคาของ Selected Side ต้องไม่เกิน Maximum Odds และ Minimum ต้องไม่มากกว่า Maximum

8. Maximum Price Age (seconds)

Default 90s1–3600 วินาที

อายุสูงสุดของราคาที่อนุญาตให้ใช้สร้าง SIGNAL เป็นการเช็ก freshness ของ quote ไม่ใช่อายุของ SIGNAL

ตัวอย่าง: ตั้ง 90s · ราคาอัปเดต 12:00:00 · ตรวจ 12:01:10 อายุ 70s ผ่าน · ตรวจ 12:01:40 อายุ 100s → stale และไม่ใช้ราคานั้นสร้าง SIGNAL
ลดค่าราคาสดขึ้น แต่เสี่ยง NO ODDS/STALE มากขึ้นเมื่อ feed ช้า
เพิ่มค่าทน feed delay มากขึ้น
ทุก Sideใช้กติกา freshness เดียวกัน

9. One Signal Per Match

Default ON

ON = เมื่อคู่หนึ่งเคยถูก lock SIGNAL แล้วจะไม่ lock ซ้ำในคู่เดียวกัน ไม่ว่าฝั่งที่ candidate ภายหลังจะเป็น HOME หรือ AWAY · OFF = เปิดทางให้ระบบ lock ซ้ำตาม state/cycle ได้

สำหรับ BOTH: ค่า ON ช่วยให้หนึ่งคู่มีหนึ่ง SIGNAL ตามโครงสร้าง 3.41 ปัจจุบัน ไม่ยิง HOME และ AWAY สองรายการพร้อมกันในคู่เดียว
กติกา AH + Settlement: engine เก็บตลาดในรูป canonical HOME แต่ก่อนสร้าง SIGNAL จะ normalize ตาม Selected Side เช่น HOME -0.50 ↔ AWAY +0.50 และใช้ odds ของฝั่งเดียวกัน เมื่อ lock แล้ว SIGNAL เก็บ selection เป็น HOME หรือ AWAY จริง จากนั้น settlement ใช้มุมของ selection นั้นในการตัดสิน WIN / LOSS / PUSH
