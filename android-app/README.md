# NOMADTIPS3 Android

Direct-install Android shell for the official NOMADTIPS3 website.

- Package: `com.nomadtips3.app`
- Version: `1.0.0`
- Website: `https://www.nomadtips3.com/`
- Launcher icon: vintage NOMADTIPS3 wordmark

The app keeps live football data on the existing website/engine path; it does not duplicate or cache live score, odds, signal, or match logic inside the APK.
